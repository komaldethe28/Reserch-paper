# Reserch-paper Manager
 full-stack **Reserch-paper Manager** application built with **MERN** (MongoDB, Express.js, React, Node.js) that allows Teacher to manage and publish Research, Paper, Notes and Articles efficiently. The app provides secure authentication and interactive dashboards

## About
This project is a web application designed to support a research paper platform. 
It includes both frontend and backend components. 
The goal is to allow Teacher to manage research documents, analytics, notes and related content.

## 🛠️ Tech Stack

- **Frontend:** React, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (via MongoDB Compass)  
- **JWT authentication and REST API**
